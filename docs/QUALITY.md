## 3. איכות החיפוש מקצה לקצה (`npm run eval:search`)
- **מה זה:** 45 חיפושים אמיתיים. AI שני ("שופט", gpt-5.5, חזק מהבוט) בודק אם כל אחד מ-4 המוצרים הוא באמת מה שביקשו.
- **המדד (45 חיפושים):** כמה מתוך 4 המוצרים הם המוצר הנכון, וכמה מתאימים לכל התכונות שביקשו.
  - 23.10: **85%** מוצר נכון.
  - 24.10, אחרי הסינון לשתי דרגות (מדויק / חלקי): **92%** מוצר נכון, **73%** עם כל התכונות, 0 חיפושים עם פחות מ-4 תוצאות.
  - 24.10 בצהריים, אחרי שה-AI רואה גם את תמונות המוצרים (gpt-5.4-mini): **84%** עם כל התכונות (צבע, מגדר, שימוש), **89%** מוצר נכון (השופט רואה עכשיו תמונות, ולכן הוא מחמיר יותר), זמן חציוני 5.8 שניות (היה 4.1).
  - 24.10 אחר הצהריים, השוואה עם אותו שופט (gpt-5.4-mini): **gpt-6-luna** קיבל 94% מוצר נכון ו-75% עם כל התכונות, ב-$0.0006 לחיפוש. gpt-5.4-mini קיבל 95% ו-71%, ב-$0.0032. עברנו ל-luna, שזול פי 5.
  - 25.10 בלילה, אחרי סבב הדיוק המקסימלי (gpt-5.4-mini, חיפוש קצר, מוכרים מוכחים קודם): שופט מחמיר ובלתי תלוי (gpt-5.4) נתן **87%** מוצר נכון ו-**81%** עם כל התכונות (הגבוה עד כה). **0 מתוך 45** חיפושים עם פחות מ-4 תוצאות. עלות: $0.003 לחיפוש.
  - 25.10 בבוקר, בדיקת ההתאמה על gpt-5.4 (כותרות בלבד, תמונות רק לצבע), בדיקת AI אחת לשני החיפושים, ושופט gpt-5.5: **97%** מוצר נכון (הגבוה עד היום) ו-**82%** עם כל התכונות. $0.0054 לחיפוש לפני הזיכרון של 6 שעות.
  - עלות: `eval:search` מדפיס עכשיו את עלות ה-AI לחיפוש. כל הרצה מלאה עולה כ-10–30 סנט, כי היא כוללת גם שופט.
  - עדיין חלשים: "מגפיים לנשים" (עלי אקספרס מחזיר בעיקר נעלי חורף), "לגו טכני", "מברגה נטענת".
- **מתי:** לפני ואחרי כל שינוי בחיפוש, ב-AI או בסינון, כדי לראות אם שיפרנו או קלקלנו. עולה פחות מסנט.

## הגדרה (פעם אחת)
1. **`ADMIN_USER_ID`:** שולחים לבוט בפרטי `/myid`, ואת המספר שחוזר מוסיפים ב-Render ← Environment.
2. **סודות ב-GitHub לבדיקה היומית:** מריצים בטרמינל, בתיקיית הפרויקט. הערכים עוברים ישר מקובץ `.env` ל-GitHub, בלי להופיע על המסך:
   ```bash
   for k in OPENAI_API_KEY ALI_APP_KEY ALI_APP_SECRET ALI_TRACKING_ID; do grep "^$k=" .env | cut -d= -f2- | tr -d '\n' | gh secret set "$k"; done
   ```
3. **הרצה ראשונה ידנית:** GitHub ← Actions ← Daily check ← Run workflow.
