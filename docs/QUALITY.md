1. **`ADMIN_USER_ID`:** שולחים לבוט בפרטי `/myid`, ואת המספר שחוזר מוסיפים ב-Render ← Environment.
2. **סודות ב-GitHub לבדיקה היומית:** מריצים בטרמינל, בתיקיית הפרויקט. הערכים עוברים ישר מקובץ `.env` ל-GitHub, בלי להופיע על המסך:
   ```bash
   for k in OPENAI_API_KEY ALI_APP_KEY ALI_APP_SECRET ALI_TRACKING_ID; do grep "^$k=" .env | cut -d= -f2- | tr -d '\n' | gh secret set "$k"; done
   ```
