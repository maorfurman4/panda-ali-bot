# תוכנית בדיקות מקיפה – פנדה דילים

איך להשתמש: לשלוח כל הודעה מהעמודה "לשלוח", לבדוק שקרה מה שכתוב ב"צפוי", ולסמן ✅ או ❌. אם יש ❌, לצלם מסך.
"קבוצה" = קבוצת הבדיקות. "פרטי" = צ'אט פרטי עם הבוט.
⏱️ אם הבוט לא היה פעיל 15 דקות, התשובה הראשונה מגיעה אחרי כ-50 שניות (השרת "מתעורר"). זה לא באג.
