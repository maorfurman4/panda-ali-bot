# Fashion Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fashion cards are led by proven best sellers that look clean, classic and elegant, and a requested color is never lost to a listing's first photo.

**Architecture:** Four separate uploads on the `fashion` branch, each one tested by the owner in Telegram before the next starts:
- wording hints and the color trigger (done)
- the style judge's taste (prompt)
- a relative sales floor (code)
- the color-variant rescue (code plus one photo-picker call)

**Tech Stack:** Node.js (ESM), `node:test`, the AliExpress affiliate API, OpenAI judges (`query.js`).

**Spec:** `docs/superpowers/specs/2026-11-05-fashion-design.md`

## Global Constraints
- No paid AI runs: free checks only (AliExpress API, pool code with stub judges, unit tests).
- Extra cost per fashion search: at most ½¢. Searches with no color named get no new AI calls.
- One change per upload. Upload only after the owner says "תעלה". Push `fashion:main` only if `npm test` shows `ℹ fail 0`.
- Never write "comes in <color>" without evidence. The evidence is the title naming that color among several.
- Hebrew card copy in the voice of the existing notes (`format.js` `*_NOTE`).

## Review Focus
1. A color search where every head listing is dropped by the photo look. Expected: the rescue step still runs, and the card is not empty when the picker finds photos.
2. A search with few strong sellers (חליפה לגבר, about 23 real). Expected: the relative floor falls back to 100, so the card is no emptier than today.
3. "שמלה לבנות" (white or girls). Expected: the color rescue does not treat "לבנות" as white when `forWhom` says girls.
4. A picker that fails or times out. Expected: the card stays as the photo look left it (fails open).
5. A title naming only another color (`offColor`). Expected: never rescued with "comes in" text.
